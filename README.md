# Введение в машинное обучение

Материалы блока ДПО MLSecOps с *очень* коротким введением в ML

## Структура репозитория:

```
.
├── notebooks/              # Практические Jupyter-ноутбуки по темам курса
│   ├── 1/                  # Семинар 1: линейная регрессия
│   ├── 2/                  # Семинар 2: обучение с учителем
│   ├── 3/                  # Семинар 3: обучение без учителя
│   └── 4/                  # Семинар 4: глубокое обучение
├── slides/                 # Учебные слайды курса
│   ├── html/               # Интерактивные HTML-версии презентаций
│   │   └── img/            # Изображения, используемые в HTML-слайдах
│   └── pdf/                # PDF-версии презентаций
├── ML_1_Введение.pptx      # Исходный файл презентации «Введение»
├── ML_4_глубокое_обучение_доп_слайды.pptx  # Дополнительные слайды по DL
└── README.md               # Описание репозитория
```
